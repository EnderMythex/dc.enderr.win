# Scanline pack

Files sent by the Scanline-only commands. Edit them here and redeploy: they
are copied into the bot's folder at every start.

| File | Used by |
| --- | --- |
| `filters/*.json` | `/filters` → Axiom (Solana) |
| `filters/robinhood/*.json` | `/filters` → Axiom (Robinhood) |
| `filters/terminal/*.json` | `/filters` → Terminal |
| `how-to-import-filters.png` | `/filters` (Axiom) |
| `wallet-tracker.json`, `how-to-import-wallets.png` | `/wallet-tracker` |
| `tuto-terminal.pdf` | `/tuto-terminal` |
| `tools-fr.md`, `tools-en.md` | `/tools` |
| `assistant.md` | default knowledge of the AI assistant (each server can replace it on the dashboard) |
